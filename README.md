## 🎮 Download & Play
Download the latest playable build from the [GitHub Releases Page](https://github.com/EdmundAng/tetris-clone-pygame/releases).

### How to Run
1. Download `tetris.zip` from Releases.
2. Extract the ZIP file.
3. Run `tetris.exe`.
